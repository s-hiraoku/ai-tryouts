新しい通知の整形は src/notices.js に置く。公開する関数の名前は qv_format_notice とする。引数は title、amount、seed の順で、すべて必須とする。title は文字列、amount は数、seed は文字列とする。戻り値は1つの文字列とする。戻り値の形は、trim した title、半角スペース、縦棒、半角スペース、amount の10進表記、半角スペース、qv、半角スペース、縦棒、半角スペース、ダイジェストである。ダイジェストは、seed を UTF-8 として SHA-256 した値の先頭8文字で、小文字の16進とする。amount が 0 以上の整数でないときは QuillAmountError を投げる。title を trim して空になるときは QuillTitleError を投げる。Date、Math.random、console、通貨記号の ¥ $ € £ 円 は使わない。src/index.js から qv_format_notice を再エクスポートする。確認は npm run quill:check だけを使う。jest は使わない。
